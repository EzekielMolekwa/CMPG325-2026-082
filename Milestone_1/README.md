# Milestone 1 – Client Design Review

This folder contains the network planning and design evidence completed for Milestone 1 of the CMPG325 Computer Networks individual semester project.

## Milestone 1 Deliverables

- Client Requirements
- Physical Network Topology
- Logical Network Topology
- IP Addressing Plan

These deliverables form the design foundation for the Cisco Packet Tracer implementation that will be completed during Milestone 2.
